# P1 — Test harness + the v2.0 audit bugs

## 0. Harness first
Create `tests/ui_v2_1/spec.py`, modelled on `tests/ui_v2/spec.py` (same Report class, fixture interception, port
8081): `PHASES = ["P1".."P6"]`, `--url --upto --out --shots`, `@check("id", phase="P1")` registry, exit 1 on any
failure, `report.json` in `--out`. Add a helper `settle(page)` that waits until no element's text contains
"Loading" (max 8 s) — every content check calls it first. Add a gateway-error mode (route answers HTTP 500)
and a request counter. `tests/ui_v2_1/README.md`: how to run it.

## 1. A1 — Test property sections never finish loading (CRITICAL)
`schLoad`, `srvLoad`, `infraLoad`, `climLoad` re-render only when `S.view === "analysis"`; v2.0 renamed the view
to `property`. Opening a Test property link leaves Schools on "Loading schools near the pin…", Infrastructure on
"Loading the project geometry…" and **Services shows 0 in every category** (Södermalm pin 59.31972,18.07194:
page says Grocery 0; `dist/services/0180.json` has 31 groceries, 343 restaurants/cafés, 80 transport stops
within 1 km). Fix with one helper (`isPinView()` or similar) used by every loader; grep the whole of app.js for
any other `"analysis"` view check left over from the rename. Also: while a file for the pin's kommun (or a
neighbour) is still loading, a section says "Loading…", never 0 or "none within".
Checks: cold-open `#property?p=59.31972,18.07194:Test` → after settle no "Loading" text; grocery within 1 km
equals the count computed in the test from `dist/services/0180.json`; schools table has 6 rows; infra section
has either a table or the "No mapped project" sentence. Same for a Göteborg pin (57.7089,11.9746).

## 2. A2 — Listings retry storm
`lstSectionBody → lstWantPin → lstFetchPin`; on error the pin key is deleted and the `finally` refresh calls
`lstSectionBody` again → a tight refetch loop (~90 requests in 14 s). After an error: no refetch until the
reader presses Retry. The map's listings layer: at most one automatic retry with backoff per box.
Check: gateway answers 500 → ≤ 2 requests to it in 10 s on Test property, and the error line with Retry shows.

## 3. A3 — Quarterly crime periods
Brå preliminary quarters arrive as `"2026 prel.K1"` and that string is the period key and the select label;
2026K2 is missing from the list. Normalise in `scripts/import_bra.py` (or where the quarterly CSV is read) to
`2026K1` + a preliminary flag carried through to the UI as a small "prel." badge next to the period; include
every published quarter. With a quarter selected the map area card keeps its five headline tiles and the
"as of" label names the selected quarter. The values are single quarters (Stockholm ~41–50 vs 191.6 per year)
while the v2.0 changelog calls them a rolling four-quarter sum: relabel them "single quarter" everywhere and
correct the changelog text (don't invent a rolling sum). Rebuild with `make build`.
Check: every option of the period select matches `^\d{4}(K[1-4])?$`; prel. periods show the badge; tiles
present with a quarter selected.
