# P2 — "Map only" mode (owner's wish)

A clear way to see the map with no indicator fill.
- First chip in the chip row: **Map only**; also the first entry of the indicator picker. URL: `ind=none`
  (round-trips through `route_core.js`; add codec tests in `tests/route.test.js`).
- In this mode: no choropleth fill; boundaries drawn as thin neutral outlines (kommun nationally, RegSO/DeSO
  when drilled) that stay clickable with a hover highlight; no indicator legend; period control hidden; the info
  strip reads "Map only — pick an indicator to colour the areas". Clicking an area opens the same card/popup
  as usual (figures still shown there).
- Every Layers ▾ layer (rental listings, services, public buildings, schools, infrastructure, police-designated
  areas, climate zones where applicable) works on top exactly as with an indicator.
- Keyboard: `0` toggles Map only (ignored while typing in an input).
- Also available on the area page and Test property mini-maps via the picker's Map only entry.
- Basemap: in Map only mode the basemap may be slightly stronger (labels readable) — keep it subtle.
Checks: `#map?ind=none` → zero filled area paths, outlines present, legend absent, a layer toggles on and off,
hash unchanged after reload; key 0 toggles; `#area/kommun/0180?ind=none` mini-map has outlines only.
