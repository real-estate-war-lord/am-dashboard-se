1. **Map first.** At 1366×768 the map starts ≤ 200 px from the top and fills the rest of the screen. The selected
   area's card (name, five tiles, Open page, Chart, Outlook, Upcoming projects) becomes a collapsible panel over
   the map's right or left edge (not a block above it); collapsed state remembered in the URL. On 390×844 the map
   is inside the first screen and the card is a bottom sheet. Legends must not collide with the panel.
   Check: map container top ≤ 200 px at 1366×768 and ≤ 844 px at 390×844 on `#map` and `#map/0180`.
2. **Page weight.** `dist/index.html` is 17 MB (5 MB gzip) because every RegSO ring is inline. Move RegSO (and
   DeSO if still inline) geometry to lazily loaded per-kommun files under `dist/` (quantised GeoJSON or
   TopoJSON — pick one, document it), keep kommun outlines inline, load the files on drill-down / pin / area page
   with the same "Loading…"-never-zero rule. Target: initial `dist/index.html` ≤ 5 MB. Every view that draws
   sub-areas must still work, including export "All area data" (it must fetch what it needs first).
   Check: size of dist/index.html ≤ 5 MB; `#map/0180?lvl=regso` draws 127 RegSO paths after settle;
   `#area/regso/<a real code>` renders; export All area data row count unchanged vs v2.0 (compute in test).
